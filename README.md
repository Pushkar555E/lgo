# Landslide Monitoring Project

This repository contains the source code for the Landslide Monitoring Project.

## Structure
- **BACK+FRONT**: Contains the React/TypeScript frontend and related API/Database sync logic.
- **GEO+FRONT**: Contains mapping or geographical interfaces.
- **MODEL**: Contains predictive modeling components.
- **SMS TRIGGER**: Contains logic for sending SMS alerts based on monitoring data.
- **landslide_monitoring_schema.sql**: Database schema for the project.
